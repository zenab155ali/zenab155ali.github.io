FEATURED PROJECTS

Featured ↗

Automated Animal Feeding Machine

IoT · Embedded · Web & Mobile Dashboard

A complete hardware-software product that feeds animals automatically. The machine is built from SolidWorks-modeled mechanical parts driven by multiple motors, with embedded C/C++ (plus MicroPython for auxiliary logic) on an M5Stack controller. Every animal has its own ID, so the machine dispenses that animal's own schedule and portion size, and keeps the feeding door locked unless it's that animal's turn to eat. A companion dashboard and mobile app show exactly what happened with each animal — who ate, where, how much, calorie intake and timing — so owners can check in and stay reassured while they're away, and a remote-control UI handles scheduled dispensing and live status. Piloted with ~20 animal owners and breeders across different animal types at home; several asked for their own unit.

Sea The Truth

Marine Pollution Data Platform

A React web platform raising awareness of marine pollution, combining software engineering with UI/UX design. Interactive Leaflet maps and Recharts dashboards visualize microplastic concentrations, alongside pollution reporting, a plastic-footprint calculator and beach-cleanup events. Inventory & Orders Microservices

Event-Driven Polyglot System

An Inventory service (Python/FastAPI) and an Orders service (TypeScript/NestJS) that talk over real HTTP and atomically reserve stock, plus an event-driven Notification service that reacts to order.placed messages over RabbitMQ. Containerized, tested end-to-end, and deployed via a CI/CD pipeline with dependency vulnerability scanning built in.

Real-Time AI Safety Monitoring

Computer Vision · PPE Compliance

A real-time safety system that watches a live camera feed and checks whether workers are wearing the required safety gear (PPE). YOLO detects people and gear in every frame, Norfair tracks each person across frames, and OpenCV runs the video pipeline — engineered for high processing throughput. When someone isn't compliant, a backend raises an automated alert and logs the incident for review. Tested with 56 users across real construction / work-site scenarios, with high success rates detecting compliance on safety gear.
